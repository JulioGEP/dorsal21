EIXA HUB v1.6 - REFACTORIZACIO CONTROLADA

Aquesta versio conserva les dades i funcionalitats de la v1.5.
No cal modificar les regles de Firestore si ja vas publicar les de la v1.5.

CANVIS PRINCIPALS
- Firebase centralitzat a js/core/firebase.js
- Estat global centralitzat a js/core/state.js
- Utilitats comunes a js/core/utils.js
- Tractament d'imatges a js/services/media.js
- Documentacio tecnica: ARCHITECTURE.md i CONTRIBUTING.md

PUBLICACIO
1. Entra al repositori GitHub EIXA-Hub.
2. Add file > Upload files.
3. Puja TOT el contingut d'aquesta carpeta.
4. Missatge del commit: v1.6 - Refactoritzacio controlada
5. Commit changes.
6. Espera el desplegament automatic de Netlify.
7. Recarrega la web amb Cmd + Shift + R.
